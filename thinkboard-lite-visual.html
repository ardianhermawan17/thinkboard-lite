The loop

3 of the 7 pipeline stages · ~1 LLM call per highlight

A member marks a region of the workspace PDF. That mark is a focus point. Notes attached to it are the evidence. The model writes a small conclusion per point, then one conclusion for the whole workspace — once for you, once for the team.

One screen

tablet authors · desktop analyses · phone reads

A document canvas with a Figma feel — pan, pinch-zoom, floating tools, live cursors — rather than an infinite board. Real text selection needs the PDF.js text layer, which is DOM. Put the whole page inside a canvas scene and you lose exact text, then pay to OCR words that were already perfect.

Text layer for selection. A Konva layer on top for stylus ink and marquee regions — the only place OCR runs, and only on the cropped rectangle.

What was cut, and what it bought

against ThinkBoard Full
FullLiteWhy that is safe
Seven pipeline stagesThreeSame pipeline_stage enum, a subset of its values. Adding the rest later means emitting more rows, not migrating.
Go orchestration gatewayDeferred — server code sits in apps/web/src/server/ under the gateway’s own package namesGo was chosen for 450 users × 8 hours of streaming. Lite has neither. The port is mechanical because the folder names match.
Gateway bypasses RLS, so Go must re-implement every policyDeleted outright — no service-role key anywhereThe biggest deletion available. No bypass means no second copy of the authorisation rules to keep in sync.
Context-warning drift heuristicDeferred, but the scope embedding is still writtenThe PDF is the scope anchor in Lite. Turning the heuristic on later needs no backfill.
20/80 internet / material retrievalMaterial onlyWeb search is the slowest and most rate-limited leg, for the smaller share of context.
Bring-your-own LLM key via VaultShared free-tier pool onlyThis is Full’s own documented fallback path, so nothing has to be undone. Resolving Vault secrets in the web tier is exactly what Full pushed into the gateway.
Temperature scored through Research → Validation → QuestioningComputed by rule from human evidenceWith no validation stage, a model-invented confidence number is decoration. Count backers, corroborations, limitations and text accuracy instead — explainable in one tooltip.
